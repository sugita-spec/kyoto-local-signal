# KYOTO LOCAL SIGNAL

京都市中京区の事業者30件を整理したマーケティング営業ダッシュボードです。業種・営業ステージ・優先度で絞り込み、公開情報、Googleマップ、Instagram、6店舗分の提案用ホームページを確認できます。

候補リストの各行に「Instagram」と「ホームページ」のボタンを並べています。提案用ページは `#/restaurants/<店舗ID>` で表示し、店舗ごとの写真、紹介、特徴、おすすめ料理、利用シーン、初回来店ガイド、住所・営業時間・アクセス、FAQ、Instagram・Googleマップへの導線をまとめています。

各店舗ページの料理名や営業情報には公開情報の確認元リンクを付けています。価格・提供状況・支払い方法など変更されやすい内容は断定せず、Instagramまたは店舗への確認を案内します。

## 起動

```bash
npm install
npm run dev
```

## 本番ビルド

```bash
npm run build
```

Cloudflare Pagesでは、ビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定します。

## 注意

- 掲載状況は2026年7月30日時点の公開情報をもとにした調査候補です。
- GoogleマップやInstagramの掲載状況、営業時間、店舗の営業状況は随時変わります。
- 店舗別ページはマーケティング提案用のデモであり、各店舗の公式サイトではありません。
- 掲載写真はサイト用に新規生成したイメージであり、店舗公式の料理写真ではありません。
- 営業活動を行う前に、各店舗の最新情報を再確認してください。
